# Optimization of Cement Distribution from Depots Using a Transportation Model

**MAT304a – Operations Research | TBA Group | AY 2026–2027**

## Problem
Reproduce the balanced cement transportation case for MAISANGO Cement Nigeria Plc: 4 depots, 5 destinations, 5,100 bags of supply and 5,100 bags of demand. Minimize the sum of unit route costs times shipped bags subject to exact depot supply, exact destination demand, and nonnegative shipments.

## Files
- `transportation_model.py`: independent linear-programming solver and feasibility checks.
- `data/transportation_data.csv`: input cost matrix and supply/demand.
- `requirements.txt`: Python dependency.
- `docs/`: source paper and video script (if included).

## How to run
1. Install Python 3.10 or newer.
2. Open a terminal in this repository.
3. Run `python -m pip install -r requirements.txt`.
4. Run `python transportation_model.py`.

## Expected checks
- VAM starting allocation: **NGN 145,380**.
- Minimum transportation cost from independent LP solve: **NGN 145,140**.
- Improvement over VAM: **NGN 240**.
- Supply, demand, and non-negativity constraints: **satisfied**.

The script validates the **VAM allocation reported in the group's paper**; it does not independently implement the Vogel penalty-selection algorithm or the MODI iteration procedure. It solves the underlying LP using SciPy's HiGHS solver and separately verifies the paper's MODI-improved allocation. Multiple optimal shipment matrices may exist; the minimum objective value and constraint satisfaction are the key verification criteria.

## Model
Minimize `Z = sum_i sum_j c[i,j] * x[i,j]`, subject to `sum_j x[i,j] = supply[i]`, `sum_i x[i,j] = demand[j]`, and `x[i,j] >= 0`.
